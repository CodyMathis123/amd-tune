Safety guarantees & limitations

          
    
            
  • Default mode is fully simulated; no driver access.
    • 
            
  • Physical writes require explicit startup opt-in and a separate recovery executable.
    • 
            
  • All candidates undergo driver readback and telemetry checks.
    • 
            
  • Every experiment attempts rollback and verifies it, including cancellations.
    • 
            
  • An independent watchdog handles parent-process exits while Windows remains running.
    • 
            
  • Tests show only workload-specific evidence, not universal game stability.
    • 
          

          
The report distinguishes simulated from real GPU execution, and retains trial inputs, measurements and errors.
